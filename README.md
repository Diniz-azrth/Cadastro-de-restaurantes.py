# 🍽️ Sabor Express

Este projeto é um sistema de gerenciamento de restaurantes desenvolvido em **Python**, criado como parte dos estudos de lógica de programação. O objetivo é permitir que o usuário gerencie uma lista de estabelecimentos de forma interativa através do terminal.

## 🚀 Funcionalidades

O sistema oferece um menu interativo com as seguintes opções:

*   **Cadastrar Restaurante**: Adiciona um novo estabelecimento informando nome e categoria.
*   **Listar Restaurantes**: Exibe todos os estabelecimentos cadastrados, mostrando seu nome, categoria e status atual (Ativado/Desativado).
*   **Ativar Restaurante**: Altera o status de um restaurante para "Ativado" caso ele esteja desativado.
*   **Desativar Restaurante**: Altera o status de um restaurante para "Desativado".
*   **Sair**: Encerra a execução do programa.

## 🛠️ Tecnologias Utilizadas

*   **Python**: Linguagem de programação principal.
*   **Módulo `os`**: Utilizado para gerenciar a limpeza da tela do terminal (`os.system('cls')`).
*   **Estruturas de Dados**: Uso de listas e dicionários para armazenar as informações dos restaurantes em tempo de execução.
